Welcome to Ordinary Blog! 👋

This is a place to write about programming, Linux, small tools, and the learning process. Not every post needs to be a formal, lengthy article; sometimes a short, honest note about building something is more useful.

## Why this blog?

One of the best ways to learn a topic is to explain it in your own words. This blog helps me keep track of what I learn, understand mistakes, and share useful experiences.

## How do I add a new post?

Create a new Markdown file in the `_posts` folder. Start the filename with a date, for example `2026-10-20-my-next-post.md`, and add front matter containing its title, date, category, language, and description.

After the file is committed to the repository, GitHub Pages can build its page and include it in the homepage list.
