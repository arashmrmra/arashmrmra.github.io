# وبلاگ arashmrmra

وبلاگ شخصی دربارهٔ برنامه‌نویسی، لینوکس و پروژه‌های شخصی؛ برای ثبت تجربه‌ها، یادگیری‌ها و چیزهایی که در مسیر ساختن نرم‌افزار کشف می‌کنم.

🌐 **وب‌سایت:** https://arashmrmra.github.io

## ویژگی‌ها

- طراحی واکنش‌گرا برای موبایل، تبلت، لپ‌تاپ و نمایشگرهای بزرگ
- محتوای فارسی راست‌چین و نسخهٔ انگلیسی چپ‌چین
- تغییر زبان بین فارسی و انگلیسی
- حالت تیره و روشن
- جست‌وجوی نوشته‌ها و فیلتر بر اساس دسته‌بندی
- صفحه‌های نوشته با قالب Markdown و پیوندهای دائمی
- تنظیمات پایهٔ SEO، نشانی canonical و داده‌های ساختاریافته
- گردش‌کار ترجمهٔ فارسی به انگلیسی با کمک هوش مصنوعی؛ ترجمه‌ها برای بازبینی انسانی در قالب Pull Request آماده می‌شوند و خودکار منتشر نمی‌شوند
- بخش ارتباط با نویسنده از طریق ایمیل

## نوشتن یک مطلب تازه

۱. یک فایل Markdown در پوشهٔ `_posts/` بسازید. نام فایل معمولاً از قالب تاریخ و عنوان پیروی می‌کند؛ برای نمونه:

`_posts/YYYY-MM-DD-my-post.md`

۲. اطلاعات اولیهٔ مطلب (front matter) را در ابتدای فایل قرار دهید:

```yaml
---
layout: post
title: "عنوان نوشته"
date: 2026-10-17
description: "خلاصه‌ای کوتاه از نوشته"
category: برنامه‌نویسی
lang: fa
---
```

۳. متن نوشته را بعد از بخش front matter با Markdown بنویسید و تغییرات را به مخزن ارسال کنید.

برای نسخهٔ انگلیسی، از ساختار و فیلدهای نوشته‌های انگلیسی موجود در `_posts/` پیروی کنید و `lang: en` و مسیر مناسب را بررسی کنید.

## ترجمهٔ انگلیسی با بازبینی انسانی

مخزن شامل گردش‌کار GitHub Actions برای آماده‌سازی ترجمهٔ انگلیسی است. برای استفاده:

1. در تنظیمات مخزن، از بخش **Secrets and variables → Actions** یک repository secret با نام `OPENAI_API_KEY` تنظیم کنید.
2. در تب **Actions**، گردش‌کار **Prepare English translation** را اجرا کنید و مسیر یک مطلب فارسی در `_posts/` را بدهید.
3. Pull Request ایجادشده را بررسی کنید؛ دقت ترجمه، کدها، پیوندها، فراداده و تنظیمات SEO را پیش از ادغام بررسی کنید.

**کلید API را در کد، فایل README، ورودی عمومی گردش‌کار یا پیام‌ها قرار ندهید.** استفاده از OpenAI API ممکن است هزینه‌ای جدا از اشتراک ChatGPT داشته باشد.

راهنمای کامل‌تر در [docs/translation-workflow.md](docs/translation-workflow.md) قرار دارد.
